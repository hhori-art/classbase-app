# Monoxer連携に関する要望書

## 目的

現在開発中の理社講座用アプリ（以下、当アプリ）からMonoxerをより自然に利用できるようにし、生徒・保護者・運営側の操作を減らしたいです。

現時点では、当アプリ内にMonoxerの画面を表示しようとすると、`app.monoxer.com で接続が拒否されました` と表示されます。これはMonoxer側のセキュリティ設定により、外部サービス内での画面表示が制限されている可能性があります。

そのため、短期的には当アプリからMonoxerをリンクで開く形にし、将来的には正式な連携方法でアプリ内表示・データ連携を実現したいです。

## 現在の当アプリ構成

当アプリは以下の構成で運用予定です。

- フロントエンド: Next.js 14
- ホスティング: Vercel
- 認証: Firebase Authentication
- データベース: Firebase Firestore
- 主な利用者:
  - 生徒
  - 保護者
  - 講師
  - 管理者
- 生徒アカウント情報:
  - Firebase Authenticationでログイン
  - Firestoreの `users` コレクションに生徒情報を保存
- 講座・授業情報:
  - Firestoreの `course_registrations` や `shift_assignments` に保存
- 通知:
  - Firestoreの `user_notifications` に保存し、アプリ内通知として表示

## 短期対応

当面は、当アプリの宿題ページにMonoxerへのリンクボタンを設置します。

- スマホ・タブレットの場合:
  - Monoxerアプリを開くリンクを優先
  - 開けない場合はブラウザ版へ誘導
- PCの場合:
  - Monoxerブラウザ版を別タブで開く

この方式であれば、Monoxer側の埋め込み制限に影響されず利用できます。

## 将来的に実現したいこと

### 1. 当アプリ内でMonoxerを表示したい

当アプリの画面内にMonoxerを埋め込み表示し、生徒がアプリを切り替えずに学習できるようにしたいです。

実現したい表示イメージ:

- 当アプリの「宿題」画面を開く
- その中にMonoxerの学習画面が表示される
- 生徒は当アプリ内でMonoxerのタスクに取り組める

確認したいこと:

- Monoxerは外部サービスへのiframe埋め込みを許可できますか
- 特定ドメインのみ許可する設定は可能ですか
- 当アプリの本番ドメインを許可リストに入れることで表示できますか
- iframeが不可の場合、SSOや外部連携画面など、代替の公式方式はありますか

当アプリの想定ドメイン:

- `https://classbase-app.vercel.app`
- 将来的には独自ドメインを利用予定

### 2. アカウント追加・削除をMonoxerと連動したい

当アプリで生徒アカウントを追加・削除したときに、Monoxer側のアカウントも自動で追加・停止・削除されるようにしたいです。

実現したいこと:

- 当アプリで生徒を登録
- Monoxerにも同じ生徒アカウントを自動作成
- 学年・校舎・講座情報も可能な範囲で連携
- 当アプリで退塾・受講解除した場合、Monoxer側も停止または削除

確認したいこと:

- Monoxerにユーザー作成APIはありますか
- ユーザー更新APIはありますか
- ユーザー停止・削除APIはありますか
- 一括登録用APIまたはCSV連携はありますか
- 外部IDとして当アプリ側の生徒IDを保持できますか

### 3. 学習データを当アプリに自動連携したい

Monoxer上での学習状況を当アプリ側でも確認できるようにしたいです。

取り込みたいデータ:

- タスクの配信状況
- タスクの完了状況
- 小テストの実施状況
- 小テストの点数
- 正答率
- 学習時間
- 未完了タスク
- 動画視聴状況
- 最終学習日時

当アプリでの利用イメージ:

- 生徒画面で「今やるべきタスク」を表示
- 保護者画面で「タスク完了状況」や「小テスト結果」を確認
- 管理者画面で未完了者や低得点者を一覧確認
- 通知機能と連携し、未完了者へリマインド

確認したいこと:

- Monoxerの学習履歴を取得できるAPIはありますか
- タスクごとの完了状況を取得できますか
- 小テスト結果を取得できますか
- 動画視聴データを取得できますか
- データ取得はリアルタイムですか、定期取得ですか
- Webhookで更新通知を受け取れますか

### 4. タスク配信も自動化したい

当アプリ側の講座・授業スケジュールに合わせて、Monoxerのタスク配信を自動化したいです。

実現したいこと:

- 当アプリに登録されている講座情報をもとに対象生徒を判定
- 授業日や単元に応じてMonoxerのタスクを自動配信
- 学年・科目・単元ごとに配信内容を分ける
- 欠席や振替にも対応できるようにする

確認したいこと:

- Monoxerにタスク作成APIはありますか
- タスク配信APIはありますか
- クラス・グループ単位で配信できますか
- 生徒個別に配信できますか
- 配信期限や公開日時を指定できますか
- 配信済みタスクの変更・取り消しはできますか

## 連携方式の希望

可能であれば、以下の順で検討したいです。

### 第1希望: API連携 + SSO

当アプリからMonoxerにシングルサインオンでき、アカウント・タスク・学習結果をAPIで連携する方式です。

メリット:

- 生徒のログイン負担が少ない
- アカウント管理を一元化できる
- 学習データを当アプリ内で活用できる

### 第2希望: API連携 + 外部リンク

Monoxer画面自体は別タブまたはアプリで開き、データだけAPIで連携する方式です。

メリット:

- 埋め込みが不可でも実現しやすい
- 学習データやタスク配信は自動化できる

### 第3希望: CSV連携

APIが難しい場合、CSV出力・CSV取込で定期的に連携する方式です。

メリット:

- 初期導入しやすい
- 手動運用から開始できる

デメリット:

- リアルタイム性が低い
- 運用作業が残る

2. iframe埋め込みを許可するドメイン設定は可能か
3. SSO連携は可能か
4. ユーザー作成・更新・停止・削除APIはあるか
5. クラス・グループ連携APIはあるか
6. タスク作成・配信APIはあるか
7. 学習履歴・小テスト結果・動画視聴データを取得できるAPIはあるか
8. Webhookによるリアルタイム連携は可能か

10. 開発用のテスト環境・API仕様書を提供いただけるか

## 当アプリ側で準備できること

当アプリ側では、以下を準備できます。

- 生徒ID
- 生徒氏名
- 学年
- 校舎
- 所属講座
- 保護者との紐付け
- 受講開始月
- 受講解除月
- 欠席・振替情報
- 授業スケジュール
- 単元情報
- 通知機能

Monoxer側からAPI仕様が提供されれば、当アプリ側で連携用のAPIクライアントを実装できます。

## まとめ

短期的には、当アプリからMonoxerをリンクで開く方式で運用します。

中長期的には、以下を実現したいです。

- 当アプリ内でMonoxerを表示
- 当アプリの生徒登録・削除とMonoxerアカウントを自動連携
- Monoxerのタスク・小テスト・動画視聴データを当アプリに自動反映
- 当アプリの講座・単元情報をもとにMonoxerタスクを自動配信

この実現可否と、必要な契約・技術仕様・API提供範囲について確認をお願いします。
