# 交流広場（交流掲示板の3D版）

`/student/community/plaza`。交流掲示板の見出しの「3Dの広場を歩く」から入る。

## できること

- 承認済みの投稿（新しい順に最大50件）が看板として、噴水を囲む輪に並ぶ。新しいものほど内側。
- 視点は三人称（自分のアバターを後ろから見る）が標準で、一人称に切り替えられる（画面右上のボタン・V キー。端末に保存）。
  アバターの服の色は生徒ごとに決まった色。三人称のカメラは、看板や噴水があいだに入ると手前に寄る。
- ステージは2つ。広場の北西の「校舎・教室 →」の門に近づくと「教室に入る」が出て、暗転して教室へ移る。教室の後ろの扉で広場に戻る。
  - 教室：黒板（日付と「今日の話題」＝いいねがいちばん多い投稿）・教卓・机と椅子20組・窓とカーテン・ロッカー・時計・掲示物。
    後ろの掲示板に、新しい投稿が貼り紙として8件並び、開ける。窓から差し込む日差しが机や床に窓の形の影を落とす。窓の外は校庭と木。
- 見た目：光の反射を計算する材質、影、大気の散乱で描く空（雲つき）、芝・石畳・れんが・木目などの質感。
  画質は「きれい（影あり）」と「軽い（影なし、古い端末向け）」を選べる（メモリの少ない端末は、はじめから軽い）。
- 広場：噴水（水しぶき・波紋）と花壇、斜め4方向の通り（街灯・ベンチ）、通りの先の「交流広場」の門、外周の生け垣と木、
  北の奥の校舎と時計台（端末の時刻で針が動く）、遠くの山、流れる雲。
- 一人称視点で歩いて回り、看板の前で開くと、掲示板と同じ「いいね・投票・コメント・通報」ができる（API は `/api/student/community` をそのまま使う）。
- 操作
  - PC：クリックで視点をつかむ（Esc で解除）、WASD・矢印で移動、Shift で走る、E で看板を開く、V で視点の切り替え。
  - スマホ・タブレット：画面の左側でスティック（大きく倒すと走る）、右側をなぞって見回す。
- スマホは横向きで遊ぶ。Android（Chrome など）は「広場に入る」で全画面にし、横向きに固定する。
  iPhone の Safari は向きを固定できない（Screen Orientation の lock に非対応）ので、縦持ちのときは画面ごと90度回して見せる。
- 見回す速さを設定できる（端末に保存）。

## 作り

| ファイル | 役割 |
|---|---|
| `lib/community-plaza.ts` | 看板の配置・当たり判定・移動・スティック・回したときの指の位置の計算（テスト：`tests/community-plaza.test.mts`） |
| `app/student/community/plaza/plaza-engine.ts` | three.js の描画と操作、視点の切り替え。ページを開いたときだけ読み込む |
| `app/student/community/plaza/plaza-world.ts` | 景色とアバター（同じ形が多いものは InstancedMesh でまとめて描く） |
| `app/student/community/plaza/classroom-world.ts` | 教室の景色（配置の数値は `lib/community-classroom.ts`。当たり判定と同じ値） |
| `app/student/community/plaza/plaza-textures.ts` | 質感・黒板・時計・掲示物をその場で描く |
| `app/student/community/plaza/page.tsx` | 入口の説明、横向き、画面のボタン |
| `app/student/community/plaza/PlazaTopicPanel.tsx` | 看板を開いたときの投稿の画面 |

- 3Dの部品（地面・噴水・木・看板）はすべてコードで作っている。外部の3Dモデル・画像・フォントは使っていない（著作権の確認が要らないように）。
- Firestore の読み込みは掲示板と同じ（承認済みの投稿を最大50件、開いた投稿のコメント）。サーバーの処理は増やしていない。
- 画面が見えていない間や、投稿・説明を開いている間は描画を止める。

## 法律・安全面の確認（2026-11-06）

| 項目 | 確認したこと | この機能での扱い |
|---|---|---|
| 電気通信事業法 | 他人の通信を媒介する（1対1のメッセージなど）と登録・届出が要る。2023年の改正で、SNS・掲示板にあたる「媒介相当電気通信役務」も、利用者の範囲などによっては届出の対象になりうる | 広場は既存の掲示板の見せ方を変えただけ。**1対1のやりとり（DM・ボイスチャット・近くの人との会話）は作っていない**。足すときは、届出の要否を総務省の参入マニュアル（追補版）で確かめるか、総合通信基盤局に相談する |
| 青少年インターネット環境整備法 第21条 | 掲示板などの管理者は、青少年に有害な情報の発信を知ったら、見られないようにする努力義務がある。通報の受付体制と、措置の記録の保存も努力義務 | 看板になるのは先生が承認した投稿だけ。看板から通報でき、管理者は既存の「交流掲示板」の画面で確認・非表示にできる |
| 個人情報保護法 | — | ほかの生徒の姿・位置・動きは表示も記録もしない。看板に出る名前は掲示板と同じ |
| 健康・安全 | 3D酔い、歩きスマホ | 入口で「すわって遊ぶ」「気分が悪くなったら休む」を表示。視点の揺れは控えめ、見回す速さを変えられる |

ほかの生徒をアバターで表示する、リアルタイムで一緒に歩く、といった機能を足すときは、上の電気通信事業法の確認に加えて、未成年どうしのつきまとい・なりすましへの対策（見守り、ブロック、時間帯の制限など）と、通信量・費用（Firestore の書き込みが人数×回数で増える）を先に決める。
