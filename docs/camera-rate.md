# 授業のカメラON率

授業中にカメラがオンだった分数を Zoom から読み、カメラON率を退塾の兆しの1つとして見る。
カメラを隠してオンにすることもできるので、コインなどのご褒美には使わない（2026-11-09 にコインからこの形に変えた）。

## しくみ

- 毎晩 22:50（Vercel Cron `/api/cron/camera-time`）に、その日の授業を処理する。
- Zoom のダッシュボードの「参加者のQoS」を使う。参加者ごとに1分ずつ記録があり、`video_input`（参加者が送っている映像）に値がある1分を「カメラON」と数える。
- 授業：その日の講師配置のうち、Zoom のミーティングIDがあるもの。時間は授業ボタンの設定の時限の開始〜終了。
- 生徒：その授業に授業ボタンから入った生徒（`attendance` の `participations`）だけを候補にし、Zoom の表示名で照らし合わせる（生徒番号 → 名前が同じ → 名前の一部、の順。1人に決まらなければ記録しない）。
- 記録：`camera_session_summaries/{日付}_{講師配置ID}_{生徒ID}`。カメラONの分数・参加していた分数・ON率と、講師・時限・学年・教科・生徒の校舎。同じ日を処理し直すと上書きする。本人・保護者・先生が読めて、書けるのはサーバーだけ。

## ON率と「オフの授業」

- ON率 ＝ カメラONの分 ÷ 参加していた分。
- 参加が「判定に入れる参加」（既定 10 分）未満の記録は、ON率にも連続の判定にも入れない。
- ON率が「オフとみなすON率」（既定 20%）未満の授業を「オフの授業」とする。

## どこに出るか

- **講師の声かけリスト**（`/teacher/risk-monitor`）：オフの授業が「声かけに出す回数」（既定 3 回）続いた生徒に、理由「N回続けて授業でカメラがオフ」が出る（25点、1回増えるごとに +5、上限 40）。直近8週の記録を見る。「声かけ済み」にしても、さらにオフが続くと再び出る。
- **管理画面「授業のカメラON率」**（`/master/camera-rates`、マスターだけ）：直近7・30・90日の、先生ごと・授業ごとのON率と、続けてオフの生徒。CSVで保存できる。講師の評価にあたるため、発言チェックと同じくマスターだけにしている。

## 設定

管理画面「設定」→「表示設定」の「授業のカメラON率を見る」。既定でオン。

- オフとみなすON率：既定 20%未満
- 声かけに出す回数：既定 3 回続けて
- 判定に入れる参加：既定 10 分以上

## Zoom 側の準備

アプリが使っている Server-to-Server OAuth アプリに、`dashboard:read:list_meetings:admin` と `dashboard:read:list_meeting_participants_qos:admin` を足してある（2026-11-09）。Business 以上のプランが前提。スコープがないと `skipped: zoom-scope-missing` で止まり、何も書かない。

## 試し方

読むだけで書かない試し（CRON_SECRET が要る）：

```
curl -H "Authorization: Bearer $CRON_SECRET" "https://classbase-app.vercel.app/api/cron/camera-time?date=2026-11-10&dry=1"
```

## 注意

- Zoom の表示名が「iPhone」などで、名前でも生徒番号でもないと照らし合わせられない。
- 授業ボタンを使わずに入った生徒は対象外。今はアプリを使っている生徒が一部なので、先生ごとのON率は、その先生の授業のうちアプリから入った生徒だけの値になる。
- Zoom の記録は1分単位。
