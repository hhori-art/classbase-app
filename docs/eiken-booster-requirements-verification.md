## 要件別の実装状況

| 要件 | 状況 | 主な実装 |
| --- | --- | --- |
| 共通Firebase Auth・users | 実装済み | 既存認証と`getServerUser`を共用 |
| 受講者だけにBoosterを表示 | 実装済み | `course_enrollments`と担当・管理権限で判定 |
| 今日やる学習を1〜3件に絞る | 実装済み | 優先度、公開時刻、前提タスク、表示順を反映 |
| 動画・テキスト課題・理解度 | 実装済み | 開始、完了、3段階理解度を保存 |
| LIVE授業 | 実装済み | 受講講座、状態、参加時間をサーバー検証。秘密情報は一覧から除外 |
| 確認テスト | 実装済み | 正答を取得APIから除外し、回数制限、採点、技能別結果を保存 |
| AI添削 | 実装済み | サーバー側サービス、構造化検証、モック、失敗時再試行、二重送信防止 |
| 成長・履歴 | 実装済み | 完了率、学習日数、前週比、技能別変化、履歴を表示 |
| 保護者画面 | 実装済み | 紐づく子どもの切替、進捗、次回授業、テスト推移、お知らせ |
| 講師画面 | 実装済み | 担当講座だけの授業、受講生、進捗、要フォロー、ホスト開始 |

| Firestore防御 | 実装済み | 英検管理データの変更はRoute Handler経由。直接書き込みはマスターのみ |

## 今回修正した不整合

1. Booster専用管理者が旧・理社管理権限の校舎判定で拒否される問題を修正。
2. 一般管理者が全校舎の英検講座を変更できる可能性を除き、割り当て校舎だけを表示。
3. LIVE参加ボタンを参加可能時間内だけ表示し、時間外は開始時刻を案内。
4. 授業終了後の参加猶予時間も一覧表示の判定へ反映。
5. 受講登録と講師担当を停止・再開できる管理UIを追加。
6. 完了済みAI添削の二重送信時に、既存結果を失敗状態へ変えてしまう例外処理を修正。
7. シード講座の級コードを`grade_2`から正式な`2kyu`へ修正。

## 外部サービスを伴う確認

本番データを変更する受講登録、課題提出、Zoomホスト開始、実AI添削は、既存利用者への影響を避けるため操作していません。認証、対象講座、時間、担当範囲、入力値、保存先については、それぞれのRoute Handlerまで確認しています。専用の検証用受講者・講師とテスト用Zoomミーティングを用意した環境では、`docs/eiken-booster-test-plan.md`に沿って外部連携を含むE2E確認を行います。
