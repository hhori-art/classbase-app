# ClassBase 本番運用判定計画・監査台帳

更新日: 2026-10-10  
目的: 本アプリの機能を一つずつ確認し、機能・権限・データ・画面・運用手順の全てが本番運用可能であることを証明する。

## 合否基準

各機能は次の5項目を全て満たした場合のみ「合格」とする。

1. 正常系: 想定する利用者が主要操作を最後まで完了できる。
2. 異常系: 未入力、重複、期限切れ、外部障害時にデータを壊さず復旧方法を示す。
3. 権限: 他ロール・他校舎・他利用者のデータを閲覧または変更できない。
4. 運用品質: スマートフォン、キーボード操作、読み込み中、空状態、エラー表示が実用可能である。
5. 運用準備: 担当者、日常手順、問い合わせ先、バックアップ・復旧・切り戻し方法が決まっている。

判定は `未確認 / 確認中 / 合格 / 要修正 / 運用確認待ち` のいずれかとし、根拠のない合格は禁止する。
