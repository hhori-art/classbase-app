# Booster テスト計画

## 認証・導線

- 通常ログイン後に`/apps`が表示される。
- 理社講座だけの生徒にはBoosterカードが出ない。
- 英検受講生には理社講座とBoosterの両方が出る。
- 英検担当講師にはBoosterと勤怠が出る。
- 勤怠専用アカウントは従来どおり勤怠へ移動する。
- 各ダッシュボードからアプリ一覧へ戻れる。

## 権限

- 生徒Aが生徒Bの進捗を取得できない。
- 保護者は`student_ids`または`parent_uid`で紐づく生徒だけ見られる。
- 講師は担当登録のある講座だけ見られる。
- 一般管理者は校舎範囲外の講座・生徒を管理できない。
- 生徒へZoom ID、パスコード、参加URLの一覧が返らない。
- 生徒が得点やAI評価を直接書き換えられない。
- 本人が`enabled_programs`, `eiken_teacher`, `eiken_admin`を変更できない。

## 学習

- 公開済みタスクが`sequence`順で表示される。
- 前提タスク未完了時は次の学習に選ばれない。
- 完了と理解度が`eiken_task_progress`へ保存される。
- 確認テストの正答が取得APIへ含まれない。
- 単一選択、複数選択、短文が採点される。
- 技能別正答率が保存される。
- AI添削の同一タスク二重送信が防止される。
- AI未設定時にモック添削が返る。

## LIVE授業

- 受講講座と`course_id`が一致する。
- 参加可能時間外はURLを返さない。
- キャンセル授業へ参加できない。
- 担当外講師はホストURLを取得できない。
- 生徒カレンダーにはBooster予定だけが表示される。

## 回帰

- `/student`, `/parent`, `/teacher`, `/master`が表示できる。
- `/teacher/attendance`が保存・修正できる。
- 理社講座の授業参加と録画が動作する。
- `npm run build`が成功する。
