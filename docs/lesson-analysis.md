# 授業の振り返り

Zoom の文字起こしと、生徒のカメラON率から、授業ごとの振り返りを作る。先生の授業改善を支えるためのもので、人事評価には使わない。

## 方針（2026-11-11 に決めたこと）

- **AI は使わない**。決まり（言葉の一覧と目安の値）で判定する。追加の費用はかからず、生徒の発言を外部に送らない。
- **先生の映像は分析しない**。録画は「画面共有＋話している人」で、先生の映像がほとんど入っていないため（Zoom の「アクティブスピーカーを別に保存」「画面共有中に参加者の映像を録画」はオフのまま）。映像も含めた試作は `worker/lesson-analysis`（Python・MediaPipe）にある。
- **見られるのは理社講座の管理者**（マスターと、理社講座の権限がある管理者）。設定の変更はマスターだけ。

## しくみ

1. 録画と文字起こしは、今までどおり Zoom の通知（`recording.completed` / `recording.transcript_completed`）と日次同期で講師配置に付き、文字起こしは `lesson_transcripts/{講師配置ID}` に保存される（発言チェックと同じ）。
2. Vercel Cron `/api/cron/lesson-analysis` が、毎晩 23:20（カメラの記録 22:50 のあと）にその日の授業、翌 10:40（`?yesterday=1`）に前の日の授業の振り返りを作る。
3. 結果は `lesson_analyses/{講師配置ID}`（サーバー専用）に置く。同じ授業は上書きするので、二重にはならない。

## 分析すること

| 項目 | 中身 |
|---|---|
| 先生の話している割合 | 10秒ごとと授業全体 |
| 話す速さ | 先生の1分あたりの文字数 |
| 問いかけ | 言葉の決まりで判定。問いかけから次にだれかが話すまでの秒数（待ち時間） |
| 生徒の発言 | 文字起こしで話者を区別できたときだけ（今の授業は話者が1人のことが多い） |
| 続けて話した時間 | 先生が生徒の発言をはさまずに話した最長の時間 |
| 沈黙 | だれも話していない区間 |
| 考える・書く時間 | 問題を解く・書くよう促した発言から3分以内の、だれも話していない時間の合計。「書けた人？」などの確かめの回数 |
| 覚え方・ポイント | 語呂合わせ・覚え方・大事・テストに出る、などの言葉の回数 |
| 参加を促す声かけ | 当てる・チャット・発表などの言葉の回数 |
| カメラON率 | 授業ボタンから入った生徒の、その授業のカメラON率（docs/camera-rate.md） |

観点（導入・発問・生徒の参加・説明の分かりやすさ・時間配分・考える・書く時間）ごとに、レベル1〜4・コメント・時刻つきの根拠（先生の発言の引用）を作る。判定の材料がない観点はレベルを付けない。

## 守っていること

- 生徒の名前は「生徒A」などに置き換え、生徒の発言の本文は保存しない（根拠の引用は先生の発言だけ）。
- 文字起こしの全文は `lesson_transcripts` にあるものを使い、重複して保存しない。
- 先生ごとに振り返りをオフにできる（オフの先生の授業は作らない）。
- 作れなかった授業は理由を残し、管理画面から作り直せる。

## Zoom 側の設定（管理者向け）

- クラウド録画の自動録画：オン
- 音声文字起こし（Audio transcript）：オン
- 録画の種類：今の「画面共有＋話している人」のままでよい
- アプリの権限：今の Server-to-Server OAuth アプリのまま（新しいスコープは要らない）

## 環境変数

新しく足すものはない（`CRON_SECRET`、Firebase、Zoom の既存の値を使う）。

## 生徒アンケートに合わせた調整（2026-11-11）

「26_理社講座アンケート（回答）」のフォームの回答 1（2026-03〜11、64,449件）の満足度と自由記述を、生徒の氏名・受講番号の列は読まずに集計し、決まりを合わせた。

- 満足度：「とても満足」50%・「満足」41%・「どちらかというと満足」8%・不満側0.9%。
- 「もっとこうしてほしい」（2,379件）で多いのは、問題を解く・書く時間（約300件）、問題演習（約240件）、速さ（約240件。スライドの切り替え・ノートを書く時間が足りない）。
- 「良かったところ」（7,602件）で多いのは、分かりやすい説明（約3,300件）、問題演習（約740件）、楽しい・面白い（約730件）、時間をとってくれた（約390件）、質問・当てる（約250件）、覚え方・語呂合わせ（約250件）、まとめ・復習（約240件）、チャット（約160件）。

これに合わせて、

- 観点「考える・書く時間」を足した（改善のヒントに、アンケートの声をそのまま添える）。
- 「説明の分かりやすさ」に、覚え方・大事なポイントの言葉を加点として入れた。話す速さの上限は、文字起こしの数え方に合わせて450字/分にし、目安を超える区間が30秒以上続いたら「目立った場面」に出す。
- 「生徒の参加」に、当てる・チャットなど参加を促す声かけを入れた（話者が先生だけの授業でも判定できる）。
- 10秒以内に続けた問いかけ（言い直し）は1回と数える。
- 考える・書く時間の中の沈黙は「沈黙」に数えない。
