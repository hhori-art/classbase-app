# 交通費マスタ主要区間 調査メモ

作成日: 2026-06-27

## CSV

- `docs/transport-fares-major-hyogo.csv`

## 反映方針

- まずは講師がよく使う主要区間だけを登録する。
- 公式PDFや公式ページで確認できたものを優先する。
- 公式サイトが検索フォームのみで、一覧表を機械取得できない会社は、主要区間だけ公開運賃検索結果で補助確認した。
- 駅すぱあと API の無料枠で金額取得が可能になった場合は、API取得を優先し、このCSVは補助マスタとして使う。

## 確認した情報

### 神戸市営地下鉄

公式ページ:
https://kotsu.city.kobe.lg.jp/subway/ryokin-teiki/ryokin-hokushin-seishin-yamate/

三宮駅の公式PDF:
https://kotsu.city.kobe.lg.jp/wp-content/uploads/s03rere.pdf

三宮から西神・山手線、北神線、海岸線主要駅への普通料金をCSVに反映。

### 神戸市営バス

公式ページ:
https://kotsu.city.kobe.lg.jp/bus/ryokin-teiki/

普通区は大人230円。普通区・共同運行路線に限り、主要停留所ペアをCSVに反映。

### 神姫バス

公式NAVI:
https://navi.shinkibus.jp/

神戸市交通局ページに、神姫バスとの共同運行路線の一部は普通区料金と同じ旨の記載あり。該当する主要区間だけ暫定登録。

### 山陽電車

公式運賃検索:
https://www.sanyo-railway.co.jp/railway/search/fare/index.html

公式検索ページはあるが一覧表として機械取得できないため、主要区間だけ公開運賃検索結果を補助確認。

### 阪急・阪神・JR西日本

各社公式の運賃検索・駅情報ページを確認。一覧CSVとして機械取得できる公式データは確認できなかったため、主要区間だけ公開運賃検索結果で補助確認。

## 注意

このCSVは「主要区間の補助マスタ」です。全駅・全停留所の完全な運賃表ではありません。
全区間の自動計算は、駅すぱあと API または NAVITIME API の契約後に外部API連携で行う想定です。
