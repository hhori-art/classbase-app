## ロール定義

| 表示名 | 正規化ロール | 保存値として認識される別名 | 主な対象 |
|---|---|---|---|
| 生徒 | `student` | 未知のロールもサーバー上は原則 `student` に正規化 | 受講生徒 |
| 講師 | `teacher` | - | 講師 |
| 保護者 | `parent` | `guardian` | 生徒に紐づく保護者 |

## ネットワーク制限

`middleware.ts` は `ALLOWED_IPS` と接続元IPで画面アクセスを制御する。

| 対象 | 社内IP | 社外IP |
|---|:---:|:---:|
| `/master/*` | ○ | ×（`/403`へ） |
| `/teacher` | ○ | ○ |
| `/teacher/settings` | ○ | ○ |
| `/teacher/work` | ○ | ○ |
| `/teacher/student-preview` | ○ | ○ |
| `/teacher/attendance` | ○ | ○ |
| `/teacher/chat` | ○ | ○ |
| `/teacher/shifts` | ○ | ○ |
| `/teacher/substitutions` | ○ | ○ |
| その他の `/teacher/*` | ○ | ×（`/403`へ） |

> このIP制限は画面ルート用であり、`middleware` の matcher は `/api/*` を対象にしていない。APIは各ルートのFirebase認証・ロール判定で保護する。

## Firestoreデータ権限の原則

| データ種別 | 読取 | 作成・更新・削除の原則 |
|---|---|---|
| `users` | 本人、担当講師、管理者、連携保護者 | 作成・削除はマスター。本人更新は安全な項目に限定 |
| 生徒学習データ | 本人、担当講師、管理者、連携保護者 | 生徒本人または講師/管理者。識別子変更は禁止・制限 |
| 保護者申請 | 申請者、連携対象、管理者 | 生徒本人/連携保護者が作成、管理者が処理 |
| コミュニティ | 対象ロール、管理者 | 投稿者本人の安全な更新と管理者操作 |
| 講師勤怠・定期券 | 本人、勤怠管理者 | 本人の安全な項目または勤怠管理者 |
| 管理設定・マスター | 管理者 | `master` または対象管理アプリ権限 |
| 英検データ | 受講/担当/連携/管理範囲 | タスク実績は生徒、教材・講座は英検管理者 |

## 注意事項

- クライアントの非表示制御はUX上の制御であり、セキュリティ境界はAPI・Firestore・Storage側で確保する。
- 管理者の旧プロフィールに `admin_permissions` がない場合、互換ロジックにより理社と勤怠が許可される。段階移行完了後は明示フラグ必須化を検討する。
- `normalizeRole()` は未知のロールを `student` として扱う。新ロール追加時はクライアント、サーバー、Firestore Rulesを同時に更新する。
