# 効果音ファイル

`lib/sound.ts` は、以下の MP3 が存在する場合はそれを再生します。
未配置の場合は Web Audio API で短い合成SEを鳴らすため、ファイルなしでも動作します。
独自音源を使う場合の推奨フォーマットは MP3, 16-bit, 44.1kHz です。

- login-bonus.mp3: ピンポン系、明るい音 (約0.3-0.5秒)
- coin-acquired.mp3: コイン取得音、シャリンシャリン系 (約0.2-0.4秒)
- quest-cleared.mp3: クエスト成功音、ファンファーレ系 (約0.5-0.8秒)
- notification.mp3: 通知音、シンプルなチャイム (約0.3秒)

## ライセンス注意

各音声ファイルは自由に使用可能なライセンスで取得してください。
例: Pixabay Sounds, Freesound, Zapsplat など

## フォールバック

ブラウザの自動再生制限や音声ファイルの 404 が発生した場合でも、SEは非重要機能として画面操作を止めません。
ユーザー設定 `settings.sound_se` が `false` の場合は再生しません。
